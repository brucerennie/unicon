Debian / Ubuntu (.deb)

Download the package for your release and architecture, for example Ubuntu 24.04 amd64 or Debian 13 arm64. From the directory where you saved it:

sudo apt install "./unicon_<version>_<arch>.deb"

Quote the filename. It contains ~, which the shell would otherwise treat as your home directory. apt installs the shared libraries the package needs. A local file is not signed, and apt may say so; that is expected. dpkg -i does not install those libraries. If you use it, run sudo apt-get -f install afterward.

Fedora / Rocky Linux (.rpm)

Download the Fedora 44 or Rocky Linux 9 x86_64 package that matches your system. The two are not interchangeable. From the directory where you saved it:

sudo dnf install "./unicon-<version>.rpm"

Quote the filename because it contains ~. dnf installs the dependencies. rpm -i does not.

Windows

Download the 64-bit .exe and run it. The installer is unsigned, so Windows may report an unknown publisher. It adds the Unicon bin directory to the system PATH. Open a new terminal after installation so the updated path is picked up.
