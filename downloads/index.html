Download the 64-bit .exe and run it. The installer is unsigned, so Windows may report an unknown publisher. It adds the Unicon bin directory to the system PATH. Open a new terminal after installation so the updated path is picked up. A path containing nographics is built with --disable-graphics and --disable-audio.
